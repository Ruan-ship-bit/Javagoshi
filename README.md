# Javagoshi
avagoshi 🐣☕ Um Tamagoshi (bichinho virtual) feito em Java puro para console.  Objetivo: Praticar Programação Orientada a Objetos (POO), concorrência (Threads e Schedulers) e manipulação de terminal (ANSI escapes). O projeto simula um ciclo de vida real, onde o bichinho sente fome, sono e tem sua felicidade calculada em tempo real.
